# Lemvori ECG Academy

Україномовна навчальна академія ЕКГ та окрема приватна панель Lemvori ECG Control.

## Запуск академії

Потрібен Node.js 24.

```sh
npm ci
npm run dev
npm run typecheck
npm run test
npm run build
```

Основний сайт працює як React/Vite застосунок і Cloudflare Worker. `.openai/hosting.json` прив’язує його до чинного Sites-проєкту. Збірка створює `dist/server/index.js` з фронтендом, API та бібліотечними файлами. `DB` — серверна D1-база, схему описано в `db/schema.ts`, міграції в `drizzle/`. Нові міграції створюються через `npx drizzle-kit generate` і застосовуються під час публікації Sites. Конфігурація OAuth й службовий токен задаються через runtime secrets, поза Git.

Локальний Vite використовує окрему SQLite-базу в ігнорованій `.openai/local/`, застосовує міграції та обслуговує ті самі API. Локальні дані не публікуються. У production використовується D1. Тести використовують SQLite в пам’яті та перевіряють права доступу, цикл чернетка → публікація → зняття з публікації, валідацію сигналу, OAuth state/PKCE і резервне джерело PTB-XL.

## Реєстрація та вхід

Email-реєстрація та вхід працюють через `/api/register` і `/api/login`. Паролі 12–128 символів зберігаються як PBKDF2-SHA256 із випадковою сіллю та 100 000 ітерацій. Сервер перевіряє Origin, обмежує спроби входу й створює сесії у HttpOnly Secure cookie. Після email-реєстрації користувач отримує одноразовий резервний код для відновлення пароля. Код зберігається в базі лише у вигляді SHA-256-хешу. Наявний користувач може створити або замінити його у профілі після підтвердження поточного пароля. Скидання через `/api/recover` одноразово споживає код, змінює пароль і завершує попередні сесії в одній транзакції. Листи та підтвердження email наразі не підключені. Google-клієнт є незалежним способом входу.

## Google-вхід

Створіть OAuth-клієнт типу Web application у Google Cloud. Для основного сайту додайте його origin та redirect URI `/auth/google/callback`. Точні адреси вказані в панелі Control у розділі «Підключення».

Runtime settings основного сайту:

- `GOOGLE_CLIENT_ID` — OAuth Client ID.
- `GOOGLE_CLIENT_SECRET` — секрет OAuth-клієнта, позначити секретом.
- `ADMIN_SERVICE_TOKEN` — випадковий службовий секрет, однаковий на обох сайтах.

Після зміни налаштувань опублікуйте нову версію сайту. Перший Google-вхід створює профіль автоматично. OAuth використовує state, nonce, PKCE та перевірку RS256 ID token через ключі Google. Сесія зберігається в D1 за SHA-256-хешем випадкового токена, cookie має HttpOnly, Secure та SameSite=Lax. Прогрес навчання наразі залишається локальним у браузері.

До налаштування OAuth Google-кнопка показує стан підготовки. Сайт не імітує успішну реєстрацію.

## Окрема адмінка

Вихідний код розташований у `control/`. Вона збирається окремо:

```sh
cd control
node build.mjs
```

Для окремої публікації використовуйте її власний Sites project_id, збережений у конфігурації окремого checkout. Не використовуйте project_id академії. Доступ до Control — owner-private, із додатковою серверною перевіркою власника через платформну ідентичність Sites.

Runtime settings Control:

- `ACADEMY_ORIGIN` — origin основної академії.
- `ADMIN_EMAIL` — email власника Sites, позначити секретом.
- `ADMIN_SERVICE_TOKEN` — спільний службовий секрет, позначити секретом.

У Control є створення й редагування наставників та кардіограм, чернетки, публікація та зняття з публікації. Публічні профілі з’являються в розділі «Наставники», записи — у «Реальні ЕКГ → Колекція академії». Завантаження доступне лише власнику через Control. JSON-сигнали перевіряються сервером. Додаткові матеріали потребують джерела й права використання.

Формат сигналу:

```json
{"name":"Назва запису","sampleRate":100,"unit":"mV","leads":[{"name":"II","values":[0.01,0.02,0.01]}]}
```

Приклад вище скорочений. Потрібно 250–20 000 відліків на кожний канал, однакова довжина каналів, частота 50–2000 Гц, 1/2/3/6/12 відведень, максимум 1,5 МБ. `control/sample.json` містить тестові нульові відліки для перевірки формату.

## Бібліотека

Каталог містить 21 799 PTB-XL і 48 MIT-BIH записів. MIT-BIH — початкові 10-секундні фрагменти. Частина PTB-XL збережена в репозиторії, решта підвантажується через серверний API з PhysioNet Open Data S3 та резервного офіційного PhysioNet. Час завантаження залежить від зовнішнього джерела. Інтерфейс містить пошук, фільтри, обране, кейси, паузу, часовий масштаб, амплітуду й повноекранний перегляд.

PTB-XL — Wagner et al., DOI 10.13026/kfzx-aw45, CC BY 4.0. MIT-BIH — Moody & Mark, DOI 10.13026/C2F305, ODC-BY 1.0. Джерела та ліцензії наведені біля записів і в `public/data/real-ecg/`.

Симуляції — авторські навчальні схеми, відокремлені від реальних сигналів. Матеріали академії призначені для навчання.

## Інтерфейс, матеріали та ефіри

Інтерфейс має перемикач UA / EN / PL із збереженням вибору в браузері. Уроки та статті залишаються українською, що позначено в інтерфейсі. Журнал містить 16 авторських статей. Розділ повторення прибрано. Для PTB-XL спочатку відображаються 6 відведень, для MIT-BIH — 2 наявні канали. Фільтри поєднують базу, кількість каналів, офіційну SCP-групу PTB-XL, мітку та обране. Довідник груп у `lib/scp-labels.ts` отримано з офіційного `scp_statements.csv` PTB-XL 1.0.3.

Control має розділ «Трансляції» для анонсів, активних ефірів і записів. Адміністратор додає YouTube video ID, дату, ведучого, опис і стан публікації. Відео відтворюється на сайті через YouTube-nocookie iframe після вибору ефіру. Джерело прямої трансляції налаштовується в YouTube Studio. Час у публічному розкладі відображається в Europe/Kyiv. Приховані чернетки не потрапляють до публічного API.

## Доступність і навігація

Бібліотека записів та тренування опису об’єднані в розділі «Практика». Окремі вкладки «Реальні ЕКГ» та «Перевірка знань» прибрано. Старі посилання `view=library` відкривають практику, `view=quiz` — уроки. Для тренажера використовується `view=workbench&mode=trainer`. На головній додано покроковий старт. `readability.css` задає контрастні світлі поля, видимі стани кнопок і читабельний текст форм.
